📖 How to Use — Shift Coverage Tracker

🚀 Getting Started 📋 Main Grid 🔤 Status Codes 🕐 Day View ⚡ Today & Next 4h 👥 Resources ⏰ Shifts 📍 Locations 🚩 Holidays ☁ Cloud Sync 📈 Coverage Report

🚀 Getting Started

  • Select your View Timezone from the dropdown at the top — all times and the today-highlight are based on this timezone.
  • Use the Month picker to navigate between months. The grid updates to show that month's data.
  • The main grid shows all resources as rows and calendar days as columns. Each cell is editable — type a status code directly into the cell.
  • Data is saved automatically to your browser's local storage and pushed to cloud sync if configured.

📋 Main Grid

  • Each column represents a calendar day. Click the day number to open the Day View for hour-by-hour breakdown.
  • The today's date column (#, Day, Date headers) is highlighted in yellow based on the selected view timezone.
  • A 🚩 flag icon appears on dates that are marked as holidays for any location.
  • Click any resource name row to open the Day View for that day.
  • The coverage % row at the bottom shows per-day availability percentage, color-coded green → red.
  • Use Quick Filter to search resources by name. Use ⚙ Advanced Filter to filter by shift, location, or off-day pattern.

🔤 Status Codes

Type these codes directly into any cell in the main grid:

CodeMeaningAvailability Weight
(blank)Present / Available (default)100%
PN1Part Night 1 — off 1st half, present 2nd half50%

🕐 Day View

  • Click any day number in the grid header to open the Day View for that day.
  • Shows each resource as a row with hour columns representing their shift — green = present, grey-blue gradient = partial (PN/PTO), red = absent, grey = outside shift.
  • A colour legend at the top of the Day View explains each block colour.
  • The Coverage % row shows per-hour availability percentage, color-coded green → red.
  • The Total Available row shows a headcount of available resources per hour.
  • Click an hour column to see a tooltip with coverage %, available resource count (x/y available), and a list of available resources grouped by shift start time — sorted by time left descending.
  • The tooltip also shows a No coverage section (in red) listing any hours within the selection with zero available resources, with the view timezone noted.
  • Click and drag across hours to select a range — the tooltip and Range Summary panel update to reflect the entire selected period.
  • The Range Summary panel is always visible and shows idle state ("No range selected") until a selection is made. Clicking outside the table deselects the range.
  • The tooltip positions itself smartly — above the click point by default, below if the header row would be obscured.
  • The Day View refreshes automatically when you change the timezone, edit/add/remove a resource, or change a shift config while the modal is open.
  • Click the shift label on a resource row to open a Shift Detail popout showing full shift info, with an Edit button that opens the shift editor directly.

⚡ Today & Next 4 Hours

  • The two boxes at the top show current hour coverage and next 4 hours average, updated every minute and on every sync.
  • The progress bar and percentage use a green → red gradient based on availability.
  • Click either box to open a popout showing available resources grouped by shift for that time window.
  • Only resources whose shift overlaps the time window and who are available are shown.
  • Times in the popout are displayed in the selected view timezone.

👥 Manage Resources

  • Click Manage Resources in the toolbar to open the fixed-size management panel with sticky tabs.
  • Click + Add Resource to open a popout form — enter their name, assign a shift (preset or manual), set work days, and pick a location.
  • When a shift preset is selected, the work-day checkboxes are locked to match the shift's configured days. Switch to Manual entry to set work days freely.
  • Work days are selected with toggle checkboxes — off days are derived automatically from whichever days are not selected.
  • The Preview TZ section shows how the shift times convert to any timezone, with a per-work-day conversion table including day offset labels (e.g. +1d, -1d).
  • Click the ✏️ icon to edit an existing resource. Renaming a resource automatically migrates all their stored cell data to the new name.
  • Click the ✕ icon to remove a resource.
  • Newly added or edited resources are highlighted and scrolled into view in the resource list after saving.
  • Use checkboxes to select multiple resources, then click ⋯ to apply holidays to all checked resources at once.
  • Auto-pull is paused while the modal is open to prevent data conflicts during editing. A pull runs automatically after each save.

⏰ Shifts

  • Open Manage Resources → Shifts tab to create and manage shift configurations.
  • Click + Add Shift to open a popout form. Each shift has a Label (e.g. "US Morning"), Start/End time, optional source timezone, and work-day checkboxes.
  • Work days are set with toggle checkboxes — off days are derived automatically. The shift carries its work-day pattern and applies it to any resource assigned to it.
  • The Preview TZ section in both Add and Edit Shift shows a per-work-day table of converted times in any chosen timezone, with day offset labels (e.g. +1d, -1d) when the shift crosses midnight.
  • Assign a shift to a resource via the Shift Preset dropdown when adding or editing a resource — this locks the resource's work days to the shift's pattern.
  • Shift times appear in the main grid header and day view, converted to the selected view timezone.
  • Editing a shift automatically updates all resources assigned to it and re-stamps historical snapshots.
  • Newly added or edited shifts are highlighted and scrolled into view in the shift list after saving.
  • Click ✏️ to edit a shift or ✕ to remove it. Removing a shift unlinks any resources that referenced it.

📍 Locations

  • Open Manage Resources → Locations tab to add locations (e.g. "Manila", "US", "India").
  • Each location can have its own holiday dates assigned to it.
  • Resources are assigned a location when added or edited — this links them to that location's holidays.
  • Newly added locations are highlighted and scrolled into view in the list after saving.
  • Remove a location with the ✕ button — this does not remove resources assigned to it.

🚩 Holidays

  • Open Manage Resources → Locations tab and add holiday dates to each location using the date picker and + Add button, or use ⬇ Auto-fill to fetch public holidays by country and year.
  • Newly added holiday tags are highlighted within their location card after saving.
  • In the main grid, select resources using their checkboxes, then click the ⋯ button and choose Apply holidays to checked — this fills HOL on all holiday dates for each checked resource's location.
  • Days with holidays for any location show a 🚩 flag icon in the date header. Hover to see which locations observe the holiday.
  • Holidays are per-location, so resources in different regions see only their relevant holidays applied.

☁ Cloud Sync

  • Click ☁ Cloud Sync in the toolbar to configure the sync URL (Google Apps Script web app URL).
  • Once a URL is set, data is automatically pushed 2 seconds after every change (debounced).
  • Push uses a pull-before-push merge — it fetches the server state first, overlays only your local changes, then pushes — safe for multiple users editing different cells simultaneously.
  • Click ⟳ to manually pull the latest data from the server at any time.
  • Enable Auto-pull to automatically pull on a set interval (e.g. every 60 seconds).
  • Auto-pull is paused while editing a cell or while Manage Resources is open, to prevent overwriting in-progress edits.
  • A ✔ Saved toast appears on data changes; ✔ Successfully synced appears on push/pull completion.

📈 Coverage Report

  • Click 📈 Coverage Report in the toolbar to open the report modal.
  • Yearly view — bar chart with one bar per month for the selected year. Shows avg available / total resources and coverage %.
  • Monthly view — bar chart with one bar per day for the selected month. Labels show abbreviated day name + date number.
  • Weekly view — bar chart with one bar per week. Select a specific week to drill down into daily bars for that week.
  • Daily view — select a specific day to see an hourly bar chart with per-resource table below. Each bar shows coverage % for that hour. Click a bar to highlight the matching hour column in the table.
  • Each bar shows X/Y (avg available / total resources) and coverage % above it.
  • Bar colors use the same green → red gradient: ≥50% = green, sliding through yellow/orange to red at 0%.
  • The resource table below the chart shows per-resource breakdown: present days, half days, absences, holidays, and overall availability %.
  • The tabs and filter bar in the report modal are sticky — they remain visible while scrolling through the chart and table.
  • Historical months use a monthly snapshot of the resource list taken at the time of editing, so shift changes don't retroactively alter past reports.
